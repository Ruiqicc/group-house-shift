# 白 · 白 · 晚 · 晚 · 白 / Group House Shift

一款回合制护工（DSP）模拟游戏原型。

一周五天，排班是**白班两天、晚班两天、白班一天**。每班八小时切成 48 个时间格，一格十分钟。两位居民、五个房间，活永远比格子多——你要决定的是谁可以等。

核心机制：**做了不等于记了**。主管看不见你做的事，只看得见记录本。

## 两个班次做的事不一样

- **白班 07:00–15:00**　起床更衣、发药、早饭午饭、洗碗、打扫、洗衣、如厕协助，以及 ISP 目标活动的数据。
- **晚班 15:00–23:00**　晚饭、洗澡、睡前护理、夜间查房。天黑以后居民会出现日落期定向障碍，情绪涨得快得多。

## 其他机制

- **搭班的同事会随手替你解决问题**——洗碗、转烘干、哄人、带人上厕所。关系越好帮得越多；关系差了他反过来给你留活。他帮你做的护理，记录还是你的。
- **烂摊子会跟到下一班**：水槽里的碗、洗衣机里的湿衣服、没擦的地，第二天开班时还在。
- **精力低于 35 进入恍惚**：点动作会点错、耗时会变多。
- 每班结算 A–D，五天后周度复核决定是否转正加薪。

## 技术

单个自包含 HTML 文件，无依赖、无后端，离线可玩；键盘可达，浅色 / 深色主题自适应，手机窄屏适配。直接下载 `index.html` 双击也能玩。
